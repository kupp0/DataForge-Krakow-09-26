# Welcome to DataForge Data and AI Labs Krakow Data Forge

Welcome, Hackathon Participants! This repository hosts the source code, configurations, and comprehensive step-by-step user guides for the **DataForge Data and AI Labs Krakow Data Forge** - *Your custom data cloud experience, built by you.* 

During this session, you will build advanced AI-powered database integrations, transactional bridges, and fullstack semantic search applications using state-of-the-art Google Cloud database features.

---

## 🚀 Deployed Lab Tracks

Here are the active lab tracks provisioned for your sandbox environment:

### 1. [Lab 1: One Million Vectors, Zero Loops (AlloyDB Vectors)](labs/lab01_alloydb_vectors/user_guide.md)
Learn to manage vector embeddings at scale using AlloyDB AI, pgvector, and Google ScaNN.

### 2. [Lab 2: Disneyland Agentic Codelab (Spanner & BigQuery)](labs/lab02_spanner_disneyland/user_guide.md)
Build a zero-copy federated analytical bridge between Cloud Spanner and BigQuery with MCP.

### 3. [Lab 3: Swiss Property Search (Fullstack AI App & Gemini Data Analytics)](labs/lab03_fullstack_ai_app_property_search/user_guide.md)
Build and deploy a premium fullstack real-estate search application leveraging natural language queries via Gemini Data Analytics.
